# VipCar Club — Landing page de orçamento

Página única (HTML, CSS e JavaScript puro) para captar orçamentos de lanternagem e pintura pelo WhatsApp.

- `index.html` — página
- `style.css` — estilos (a variável `--overlay` no topo controla o escurecimento das fotos)
- `script.js` — formulário, upload da foto para o Cloudinary e envio para o WhatsApp
- `assets/` — logo, favicons e fotos

Para publicar, envie todos os arquivos para a hospedagem (ou conecte este repositório à Vercel/Netlify).

**Meta Pixel:** no `<head>` do `index.html`, troque `SEU_PIXEL_ID` (2 lugares) e remova as marcas de comentário em volta do código.
